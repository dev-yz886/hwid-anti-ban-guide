# 显卡 GPU 设备指纹与 PCIe 总线识别码：DirectX 与 Vulkan 渲染设备特征重写

## 图形渲染 API 与显卡硬件指纹获取途径
显卡作为游戏的核心渲染硬件，其指纹被现代反作弊系统全面监控：
- DXGI 适配器描述信息：游戏通过 IDXGIAdapter::GetDesc 获取 DXGI_ADAPTER_DESC 结构体，其中包含显卡型号、显存大小、VendorID（厂商ID）与 DeviceID（设备ID）；
- DirectX 与 Vulkan 设备 UUID：DirectX 12 与 Vulkan 规范引入了专门的 Device UUID 接口，为每块独立显卡分配唯一的 128 位硬件哈希指纹；
- NVIDIA NVAPI 与 AMD ADL 底层接口：反作弊通过动态调用 nvapi64.dll 提供的内部私有函数，直接获取显卡核心出厂序列号与 BIOS 固件版本号；
- PCIe 总线位置拓扑：记录显卡插在主板上的物理插槽编号（Bus/Device/Function 坐标），构建完整的硬件拓扑树。

## GPU 设备栈与显示驱动通信拦截架构
虚拟化防护技术在显卡层面的技术实现：
- 显卡总线微端口过滤（pci.sys / nvlddmkm.sys）：在显卡底层驱动堆栈中插入微端口过滤器，拦截包含总线属性查询与硬件序列号的通信报文；
- 动态重写渲染设备描述符：在 DXGI 运行时将显卡设备 UUID 返回值进行合法化掩蔽，避免真实物理指纹暴露；
- 伪装温控与风扇转速监控数据：确保所有返回给游戏的温度、功耗与时钟频率曲线真实连续，杜绝因返回死值或静态数据被反作弊启发式算法捕获。

## 显卡驱动纯净重装规范（DDU）
在排查显卡指纹异常或驱动冲突时，必须在 Windows 安全模式下使用 Display Driver Uninstaller（DDU）彻底清除全部历史残留与着色器缓存。

## 💡 常见高频答疑 (FAQ)

**问：给显卡刷第三方超频 vBIOS 能改变显卡硬件机器码吗？**
答：不能！vBIOS 只控制核心电压、频率和风扇曲线，显卡的物理核心序列号固化在 GPU 硅片内部的 OTP（一次性可编程）只读寄存器中。

**问：双显卡交火或插两块显卡能混淆反作弊检测吗？**
答：不能！反作弊会遍历主板上所有 PCIe 插槽中的设备，并将检测到的两块显卡序列号全部记录在黑名单数据库中。
