## 以太网卡 MAC 地址构成与反作弊读取机制
网卡作为进出游戏服务器的数据门户，其物理特征是反作弊识别玩家的重要维度：
- MAC 地址组成规范：前 3 字节为组织唯一标识符（OUI，由 IEEE 分配给各大硬件厂商），后 3 字节为厂商自定义的网络接口序列号；
- 反作弊读取渠道：反作弊不仅调用应用层的 GetAdaptersInfo/GetAdaptersAddresses API，更会通过内核层直接向 NDIS 库发送 OID_802_3_PERMANENT_ADDRESS 请求，直接获取固化在网卡 EEPROM 芯片中的永久物理地址；
- 传统设备管理器软改的局限：在 Windows 网卡属性中修改‘网络地址（Network Address）’只能改变 OID_802_3_CURRENT_ADDRESS（当前地址），反作弊一旦比对发现当前地址与永久物理地址不一致，立即标记为异常。

## NDIS 轻量级过滤驱动（LWF）与网络指纹防护
实现无感知底层网络特征重构的技术路径：
- 挂接在 NDIS 网络协议栈层：编写标准的 NDIS 6.0+ 轻量级过滤器（Lightweight Filter Driver），位于协议驱动与微端口驱动之间；
- 拦截 OID 硬件查询请求：当下层返回网卡永久地址 OID_802_3_PERMANENT_ADDRESS 时，过滤器截获并动态重写为符合 Intel/Realtek 厂商规范的合法随机 MAC；
- ARP 缓存表隔离与局域网污染清理：刷新本地 ARP 缓存表，杜绝局域网内部路由器将历史被封机器的 IP 与 MAC 形成绑定记录造成连坐。

## 宽带调制解调器（光猫）公网 IP 刷新 SOP
重启光猫或路由器重新进行 PPPoE 拨号，获取全新的公网动态 IP 地址，并刷新本地 DNS 解析缓存，实现网络环境全链路彻底焕新。

## 💡 常见高频答疑 (FAQ)

**问：买一个几十块钱的 USB 免驱外置网卡能解决网卡机器码吗？**
答：USB 网卡拥有全新的独立 MAC 地址，能解决网卡层面的指纹识别，但必须同时配合主板与硬盘序列号处理，否则依然会被其他硬件特征识别封禁。

**问：开启代理软件或加速器能改变本地网卡物理 MAC 吗？**
答：绝对不能！游戏加速器只改变游戏数据包在广域网中的路由中转节点，本地物理网卡的 MAC 地址对运行在本机的游戏客户端依然是完全可见的。
