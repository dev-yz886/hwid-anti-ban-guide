# 机器码标准规范自检 SOP 实操指引：从主板重置、硬件指纹扫描到环境纯净验证

> **核心导读**：标准规范的游戏硬件安全自检实操全流程手册，排查硬件指纹暴露点，验证系统纯净度与安全进游测试规范。

## 硬件指纹自检第一步：物理硬件识别码扫描导出
在重新进入游戏之前，必须完成全维度硬件特征自检：
- 打开 PowerShell 命令行，执行 Get-WmiObject win32_baseboard 获取主板 SerialNumber 与 Product；
- 执行 wmic path win32_computersystemproduct get uuid 获取当前暴露的 SMBIOS UUID；
- 执行 wmic diskdrive get serialnumber 打印物理硬盘出厂序列号；
- 执行 getmac /v 打印所有网络适配器的当前物理地址与传输名称；
- 核对比对基准：将导出的数据与历史被封禁时记录的硬件参数进行逐字比对，若有任何一项完全相同，绝对不可冒险登录游戏。

## 系统纯净度验证第二步：网络与系统深度清理
确保没有遗留任何历史连坐标记：
- 检查本地网络环境：重启宽带光猫刷新公网出口 IP，使用 ipconfig /flushdns 清空本地解析缓存；
- 检查注册表 MachineGuid 是否已完成刷新并重置时间戳；
- 检查游戏安装目录：卸载旧版游戏客户端，删除残留的 AppData、LocalLow 与 ProgramData 隐藏文件夹，重新下载正规官方安装包到全新路径。

## 安全进游验证第三步：低风险小号测试法
所有自检指标全部通过后，切忌直接登录高价值大号。先使用一个普通测试小号进入游戏新手训练营或人机模式正常游玩 2 小时以上，确认无异常封禁后方可安全回迁主号。

## 💡 常见高频答疑 (FAQ)

**问：自检如果发现某一项硬件序列号显示为‘None’或者空白正常吗？**
答：绝对不正常！如果反作弊读取到的序列号为空白或无效字符串，会直接触发‘特征异常篡改’警告，必须确保返回合规的合法字符序列。

**问：自检测试需要断网进行吗？**
答：第一阶段本地命令扫描无需断网；但在清理注册表和系统历史日志时，建议断开网络连接以防系统后台自动同步更新旧数据。
